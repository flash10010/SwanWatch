# Roadmap

## 1.1
- Friendly device labels and notes
- Disable/enable accounts without deleting them
- Per-user bandwidth history
- Export/import dashboard settings
- WebAuthn/passkey login option

## 1.2 optional adapters
- Local GeoIP database integration
- smartmontools disk health adapter
- NUT UPS status adapter
- SMTP, Telegram and generic webhook notification adapters
- Prometheus metrics endpoint

## Explicit non-goals for the default image
- Internet-facing deployment without a reverse proxy
- Automatic host updates or unattended reboots
- Arbitrary shell command execution
- Storing generated user passwords in the dashboard database
